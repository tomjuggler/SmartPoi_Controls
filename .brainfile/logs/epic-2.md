## Description
Extend the SmartPoi Controls web app to support up to 4 POIs when in Router Mode. This covers: adding 2 extra IP address fields to Network Discovery (populated only via "Discover POI"), updating outgoing requests (speed, brightness, pattern), and adding Fetch Settings sections for the new POIs. Image uploading and Danger Zone configurations are excluded from this epic.

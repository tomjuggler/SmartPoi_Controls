## Description
Extend the SmartPoi Controls web app to support up to 8 POIs when in Router Mode. This covers: adding 4 extra IP address fields to Network Discovery (populated via "Discover POI" or manual entry), updating all outgoing requests (speed, brightness, pattern, channel, router), adding Fetch Settings sections for the new POIs, and extending the Text Tab, Images Tab, Upload Tab, and Magic Bridge Tab for the new POIs. All new POIs are optional — only visible and accessible when Router Mode is enabled and their IP != '0.0.0.0'. Backwards compatibility with existing 4-POI functionality must be preserved.
